# App 首页 3D 牧场

## 运行方式

首页直接显示卫星地形、草场分区和 60 个模拟牲畜光点。顶部 KPI、告警和草场表格仍从后台读取；3D 卡片及弹窗始终标明「演示数据」，不读取或写入真实牲畜档案。

- 单指旋转，双指缩放 / 平移；在卡片外滑动首页。
- 放大、缩小、复位视角、暂停 / 继续均操作实际场景。
- 点牲畜打开模拟详情及模型弹窗。牛复用现有牦牛模型，可自动旋转与手动查看；羊显示「暂无羊模型」。
- 弹窗打开后背景停止渲染和模拟；关闭后恢复先前的手动暂停状态。点草场分区只显示分区资料。

## 共享代码与构建

`apps/pasture-3d/src/runtime/` 是桌面和 App 共用的场景内核，包含场景工厂、模型预览工厂、资源释放及手势判断。桌面 `main.js` 只负责面板、筛选、消息与模拟控件。

App 的 Vite 配置在编译前自动调用 `build-mobile-runtime.mjs`，生成 `src/static/pasture-3d/runtime.js` 并复制 `yak.glb`。该目录是被 Git 忽略的构建产物，请勿手工修改。发布静态文件时使用原子替换，避免并行构建或监听器复制到半个脚本。开发服务器监听内核与模型资产，重建后刷新页面。普通构建、H5 构建和 App-plus 构建均执行这一步，不需要另起大屏服务器。

`PastureScene.vue` 通过 renderjs 动态加载本地脚本，所有 Three.js 对象和动画留在视图层。逻辑层只交换状态、命令和可序列化的选中对象。原生 renderjs 的 `$el` 是辅助节点，适配层通过逻辑层传入的唯一容器 id 查找真正的画布宿主。`createPastureScene` 提供缩放、视角复位、播放暂停、定位、筛选、时间轴、可见性及销毁接口；`createModelPreview` 提供显示、隐藏、暂停与销毁接口。`debug` 仅用于桌面 / 浏览器回归，不经跨层消息发送。

## 地图 Key

建议在仓库根目录 `.env` 设置 `TIANDITU_TOKEN`。兼容旧的 `VITE_TIANDITU_TOKEN`，同一配置源中标准名优先。解析优先级为进程环境、当前工程 `.env`、根目录 `.env`；App 另外在根目录之前读取 3D 工程 `.env`，以便复用已有配置。

只显式注入公开的地图 Key，绝不把整份 `.env` 或 MaxKB 密钥传入前端。Docker Compose 同样支持旧别名。修改 Key 后需重新构建；原生 App 需重新打包。地图 Key 的授权范围和设备网络必须允许天地图请求。

场景脚本和牦牛模型随安装包分发，卫星影像和 ArcGIS 高程仍需联网。高程不可用时降级为明确标注的卫星影像平面模式；地图加载失败、缺少 Key、模型加载失败均有提示和重试。该功能不是离线地图。

## 生命周期与兼容性

支持 uni-app App-vue（Android）和 H5，不支持小程序 / nvue。需要可用的 WebGL2；不支持时显示说明而非白屏。Android 应验证系统 WebView 版本与图形驱动。

移动渲染上限 30 FPS、DPR 1.5、瓦片下载并发 4。路径贴地采样按 DEM 瓦片缓存 CPU 网格，避免数百个坐标重复下载和解码同一瓦片；该缓存随实例销毁。three-tile 的加载器和工作线程是库级共享资源，不在单个场景退出时全局取消或终止。页面隐藏、卡片离开可视区域、弹窗遮挡时暂停背景。页面移除时由 DOM observer 兜底释放资源，不依赖 renderjs 不支持的卸载生命周期。模型异步回调及场景初始化均拒绝已销毁实例的结果。

## 验证

```bash
npm run type-check --workspace @tiansun/pasture-app
npm test --workspace @tiansun/pasture-app
npm test
npm run build
npm run build:app-plus --workspace @tiansun/pasture-app
```
